« Je ne suis pas un robot » : le piège où c'est vous qui piratez votre ordinateur

Des sites piégés affichent une vérification qui ressemble à celles que vous connaissez. Mais au lieu de cocher une case, ils vous demandent d'appuyer sur des touches du clavier. Si vous le faites, vous installez vous-même un programme pirate.

Ici, vous pouvez essayer sans aucun risque. Faites comme si vous étiez sur un site ordinaire.

Ce qui se serait passé sur un vrai site piégé

  1. Le site copie un programme en cachette

    Au moment où vous cliquez (sur la case « Je ne suis pas un robot », sur « Comment corriger », sur « Réparer »…), le site place en secret une commande pirate dans la mémoire du copier-coller de votre ordinateur. Vous ne voyez rien.

  2. Vous la collez vous-même

    Les touches ⊞ Windows + R ouvrent la fenêtre « Exécuter », et ⊞ Windows + X puis I ouvrent PowerShell : deux outils de Windows qui servent à lancer des programmes. Ctrl + V y colle la commande pirate.

    Les touches ⌘ Cmd + Espace puis « Terminal » ouvrent le Terminal, un outil du Mac qui exécute des commandes. ⌘ Cmd + V y colle la commande pirate.

  3. La touche Entrée lance le piratage

    Le programme s'installe. Il peut voler vos mots de passe enregistrés, accéder à votre banque en ligne et à vos mails, ou laisser les pirates prendre le contrôle de l'ordinateur.

    Le programme s'installe. Il affiche souvent une fausse fenêtre qui demande le mot de passe de votre Mac, puis vole vos mots de passe enregistrés, l'accès à votre banque en ligne et à vos mails.

Pourquoi ça marche si bien

  • C'est vous qui lancez le programme : l'antivirus a beaucoup plus de mal à vous protéger.
  • Le piège apparaît parfois sur de vrais sites connus qui ont été piratés, pas seulement sur des sites louches.
  • Le petit cadenas à côté de l'adresse ne veut pas dire que le site est honnête. Les sites piégés en ont un aussi.

Faire la différence

Un vrai « Je ne suis pas un robot »

Tout se passe dans la page :

  • cocher une case ;
  • cliquer sur des images (feux, vélos, passages piétons) ;
  • recopier des lettres déformées ;
  • faire glisser une pièce de puzzle.

Un piège

On vous fait sortir de la page :

  • appuyer sur la touche Windows avec une autre touche ;
  • ouvrir « Exécuter », « Terminal » ou « PowerShell » ;
  • coller quelque chose dans la barre d'adresse de l'Explorateur de fichiers ;
  • cliquer sur un bouton « Copier » pour « vérifier » ;
  • vous annoncer à l'avance le message que vous allez voir s'afficher sur votre ordinateur, pour vous rassurer ;
  • soi-disant « réparer » une page qui s'affiche mal, un micro qui ne marche pas en visio, ou « mettre à jour » le navigateur de cette façon.

Petit test : normal ou piège ?

Pour chaque message, choisissez votre réponse. Il n'y a aucun piège caché dans ce test.

Se protéger au quotidien

  • Dans le doute, fermez la page. Si elle refuse de se fermer, fermez le navigateur. Si ça ne marche toujours pas, éteignez l'ordinateur.
  • Appelez un proche avant de faire quelque chose d'inhabituel sur l'ordinateur. Il vaut mieux un appel pour rien qu'un compte vidé.
  • Faites les mises à jour de Windows, du Mac et du navigateur quand l'ordinateur les propose lui-même, jamais quand une page web vous le demande.
  • Activez la double vérification (un code reçu par SMS ou sur l'application) pour votre banque et votre messagerie.
  • Méfiez-vous de l'urgence. « Votre ordinateur est bloqué », « dernière chance », « vérification obligatoire » : les pirates veulent vous faire agir vite, sans réfléchir.
Pour l'aidant qui s'occupe de l'ordinateur d'un proche
  • Utiliser un compte Windows standard au quotidien, pas un compte administrateur.
  • Désactiver la fenêtre Exécuter (⊞ Windows + R) : stratégie de groupe « Supprimer le menu Exécuter du menu Démarrer » (Configuration utilisateur › Modèles d'administration › Menu Démarrer et barre des tâches), ou valeur DWORD NoRun = 1 dans HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer.
  • Installer un bloqueur de publicités réputé (par exemple uBlock Origin) : beaucoup de pièges arrivent par des publicités.
  • Garder Microsoft Defender actif et à jour, et vérifier que les sauvegardes fonctionnent.
  • Faire la démonstration ci-dessus avec la personne : le souvenir du « STOP » reste bien plus longtemps qu'un conseil.

J'ai déjà suivi ces étapes sur un vrai site

Pas de panique, mais agissez vite. Dans l'ordre :

  1. Coupez internet sur cet ordinateur : débranchez le câble ou désactivez le Wi-Fi.
  2. N'utilisez plus cet ordinateur pour la banque, les mails ou les achats, tant qu'il n'a pas été vérifié.
  3. Appelez un proche de confiance ou un professionnel.
  4. Depuis un autre appareil (votre téléphone par exemple), changez vos mots de passe : la messagerie d'abord, puis la banque, puis le reste.
  5. Prévenez votre banque et surveillez vos comptes les jours suivants.
  6. Faites-vous aider par le dispositif officiel : cybermalveillance.gouv.fr ou 17Cyber.
